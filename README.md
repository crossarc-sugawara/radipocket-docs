# radipocket-docs

Android アプリ「らじぽけ」の公開ドキュメント置き場です。

GitHub Pages で公開しています: https://crossarc-sugawara.github.io/radipocket-docs/

| ファイル | 公開URL |
|---|---|
| `privacy-policy.md` | https://crossarc-sugawara.github.io/radipocket-docs/privacy-policy.html |

## 更新のしかた

`main` に push すると GitHub Pages が自動で再ビルドします。反映まで1〜2分かかります。

`_config.yml` は Pages（Jekyll）の設定です。テーマは GitHub Pages が標準で用意している
ものしか使えません。
